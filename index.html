Preparation Before University

Get a head start in your cyber security journey

Essential scripting languages for security automation and tool development.

Master Linux

Become proficient with Linux command line and system administration.

Ethical Hacking Practice

Networking & Servers

Cyber Security Roadmap

A comprehensive 4-year plan for your cybersecurity career at UNSW

Year 0 / Before University

Preparation Phase

Goal

Build foundation & portfolio for UNSW + scholarships

Programming & Scripting

Python (automation, scanners) Bash/Linux scripting Basic C/C++

Networking & Server Basics

TCP/IP, routers, firewalls, VPNs Set up your own Linux server Practice securing servers

Ethical Hacking Labs

HackTheBox TryHackMe VulnHub

Focus on web vulnerabilities (XSS, SQLi) legally. Document projects to build portfolio.

Certifications (Optional but helpful)

CompTIA Security+ - Fundamentals
Linux Essentials - Linux basics

Year 1 - Build Professional Foundation

UNSW 1st Year

Goal

Core foundation in IT + cybersecurity basics

Subjects

Programming: Python, C Computer networks & protocols Operating Systems: Linux, Windows Security fundamentals

Practice

Continue ethical hacking labs. Start small security projects:

Port scanner Vulnerability scanner Web security testing scripts

Networking Focus

Since you already know offensive basics, focus on networking: TCP/IP, Routing, VPN, Firewalls, Linux server administration (Ubuntu, Debian, CentOS). Real hackers attack networks & servers.

Tools to Practice

Wireshark Burp Suite Community Nmap Metasploit

Year 2 - Move to Advanced Security

UNSW 2nd Year

Goal

Hands-on security skills & penetration testing

Subjects

Advanced networking & server security Web & cloud application security Intro to malware analysis

Ethical Hacking & Penetration Testing

Practice in legal environments like:

TryHackMe HackTheBox VulnHub

Learn

Secure coding Advanced privilege escalation Vulnerability discovery Web app exploitation

Practice / Projects

Build penetration testing toolkit Secure Linux server / home lab Participate in CTF competitions

Certifications

CEH - Certified Ethical Hacker
CompTIA Network+ - If needed

Important

Focus on legal penetration testing, bug bounties, auditing & red-team skills.

Year 3 - Become Cyber Security Engineer

UNSW 3rd Year

Goal

Advanced specialization & defensive skills

Subjects

Ethical Hacking / Pen Testing (deep) Malware analysis & threat intelligence Network & server hardening Cloud security (AWS/Azure basics)

Switch from attacking to defending

Now focus on defensive security skills:

Server & Infrastructure Security
Hardening Linux Secure cloud servers (AWS/Azure) Log analysis & intrusion detection SIEM & monitoring
Blue-team skills
Incident response Threat intelligence Malware analysis basics

Practice

Red team labs → penetration testing Blue team labs → defending servers Build automation scripts for security

Certifications

OSCP - Offensive Security Certified Professional
AWS / Azure Security Fundamentals

Year 4 - Specialize

UNSW 4th Year

Goal

Mastery + professional readiness

Subjects

Advanced penetration testing Security management & policy Capstone project

Choose ONE specialization area

Penetration Tester (Red Team) Security Engineer (protect systems) Security Automation / Tool Developer

Portfolio / Projects

Advanced vulnerability scanner Incident response scripts Security monitoring dashboards

Career Prep

Internship in Cybersecurity Apply for jobs Build professional network

Extra for Tool Developers

Instead of DDoS tools (illegal), build: Vulnerability scanners, Port scanners, Log monitoring tools, Web security testing frameworks, Server protection scripts. That is real job skill and safe.
